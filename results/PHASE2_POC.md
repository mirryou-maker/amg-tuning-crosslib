# Phase 2 개념검증 (PoC) — 특징 추출기 + 예측 가능성 게이트 (2026-07-25)

Phase 1 데이터(50행렬)로 "특징→최적설정 예측"에 신호가 있는지 값싸게 검증.
수백 행렬 수집(수일 계산) 착수 전 게이트.

## 산출물

- `tools/compute_features.py` — Tier 0/1/2 특징 추출기 (`results/features.jsonl`).
- `tools/poc_predictor.py` — group-wise(leave-one-group-out) 예측 PoC.

## 특징 추출 비용 (문헌이 무시한 격차, 실측)

| Tier | 내용 | 시간(50행렬 실측) |
|---|---|---|
| 0 | 구조(크기·밀도·행nnz분포·패턴대칭·대각·밴드폭) | 0.002–0.16 s |
| 1 | 값(대각우세·값비대칭·Gershgorin·power-iter 고유값) | +0.01–0.18 s |
| 2 | 조건수 추정(eigsh 최대/최소) | **+3–20 s (100–1000배)** |

→ Tier 2는 이득 대비 비용을 반드시 정당화해야 함. 대부분 행렬에서 eigsh 미수렴.

## 예측 가능성 게이트 결과

| 형식 | 데이터 | 다수결 | kNN-LOGO | lift |
|---|---|---|---|---|
| 승자 분류: coarsening+relax | 26점·8클래스 | 0.31 | 0.15 | **−0.15** |
| 승자 분류: coarsening 계열만 | 26점·3클래스 | 0.69 | 0.73 | +0.04 |
| 승자 분류: relax만 | 26점·4클래스 | 0.50 | 0.42 | −0.08 |
| **성공 예측: (행렬,조합) 쌍** | **4,400점·이진** | 0.71 | **0.76** | **+0.05** |

## 판정

- **승자 분류는 신호 없음** — 원인은 명확: 26행렬/그룹당1개(Phase1이 다양성 위해 그렇게
  뽑음)/8클래스는 학습 불가. 데이터 부적합이지 신호 부재의 증거는 아님.
- **쌍 단위 성공 예측은 modest 양성(+0.05)** — group-wise 검증 통과, 4,400점 사용.
  이 재구성이 문헌 표준이자 올바른 방향. 데이터를 88배 효율적으로 씀.

## Phase 2 설계 확정 사항 (PoC가 정해준 것)

1. **예측 형식 = 쌍 단위 회귀/분류** (성공 여부 + log solve-time), 승자 분류 아님.
2. **행렬 수백 개 + 그룹당 복수 행렬** 필수 — LOGO에 학습할 그룹내 구조가 있어야 함.
3. **group-wise 분할 유지** — modest 신호가 여기서도 살아남음(과대평가 회피).
4. Tier 2는 선택적, 이득 실증될 때만.
